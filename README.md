# Adam Bateman's Portfolio Website
The title is pretty self explanatory, but I wanted to create a space to show my projects. I had a few goals in mind when making this site, and they can be found below.

1. Simplicity. No fancy transitions, no unnecessary features.
2. Performance. Following from the first point, I want it to perform well and be lightweight so things load quickly.
3. Styling. I tried to make it follow the same colour scheme as EVA-01 from Neon Genesis: Evangelion, but I had to end up compromising on the colour scheme.
4. Nostalgia. Loosely inspired by http://onemorelevel.com/, a flash game website I spent lots of time on in my childhood.
5. Learning. I want to learn the basics of how websites are structured and built. I don't want AI to build the whole thing for me.

The SVG icons used as icons came from my installation of Linux Mint on my desktop, which is why (I think?) this project uses the GNU general public License.
